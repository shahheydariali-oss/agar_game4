# اگر... v0.1
نسخه واقعی و قابل توسعه بازی روایی فارسی «اگر...». هسته Flutter، رابط RTL، ذخیره خودکار، موتور انتخاب/پیامد و دیتای 300 مرحله.

## اجرا
flutter pub get
flutter run

## APK
flutter build apk --release

مراحل 1 تا 30 محتوای روایی اولیه دارند؛ ساختار 31 تا 300 آماده است تا به شاخه‌های کامل، رازها، روابط، بدهی، دروغ، مسیرهای قانونی/زیرزمینی/عاطفی/سیاسی و پایان‌های متعدد تبدیل شود.
